my entry for [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36)

## The line

> I woke up pretty sure my bed had filed a restraining order against me, so I'm respecting the legal process today.

Half believable, one fresh idea, and the joke lands on the last words —
exactly the kind of message a real person would actually send their boss.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` /
`$OUTPUT_DIR` when set) and then reads it back, enforcing the gate itself:
1–200 characters, a single line, no leading or trailing whitespace.

```sh
node main.ts
```
